Rules

By default, two tabs are the same page when their URLs match, ignoring the #fragment, a trailing slash and http/https. Rules group more pages together. They're tried top to bottom, before online rules.

How patterns work
*
ignore this part of the URL (one path segment)
**
ignore anything, including slashes
{name}
one tab per value of this part

Put several patterns on separate lines to treat different URLs as the same page. Variables are matched by name, so the same {org} can be in the domain on one line and in the path on another:
dev.azure.com/{org}/{project}/_git/*/pullrequest/*
{org}.visualstudio.com/{project}/_git/*/pullrequest/*

Anything after the pattern (more path, the query string, #fragment) is ignored, unless the pattern contains ?; then the query is matched too.

dev.azure.com/*/*/_git/*/pullrequest/* keeps one pull-request tab.
dev.azure.com/*/*/_git/{repo}/pullrequest/* keeps one per repository.

Link wrappers

Some apps open links through a redirect page first, such as Microsoft Safe Links in Teams and Outlook. A link wrapper says where the real link is, so the tab you already have open is found straight away. The default wrappers come from the online rulesets below; add your own here.

Behaviour

When the tab you're on is itself a match: Ctrl+click, Duplicate tab, or a link from another app (Teams, a terminal) while you're on that tab. Opening the same link several times then gives several tabs.
Keeps checking a new tab for a few seconds while it's redirected (sign-in pages, link scanners without a link wrapper), and stops as soon as you navigate it yourself.
Any page on a site you already have open replaces that tab's page, unless a rule above says otherwise. Unsaved text in that tab is lost, and Close duplicates leaves one tab per site.
Hostnames, separated by commas. Subdomains are included.
Adds 🔁 to the title of duplicate tabs. Edge asks for permission to change pages on all sites when you turn this on.
