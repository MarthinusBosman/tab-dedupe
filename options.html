Your rules

By default, pages are the same when the URL matches, ignoring #fragment, trailing slash and http/https. Rules group more pages together. They are tried top to bottom, before online rules.
In a pattern, * means ignore this part, ** means ignore anything (including slashes), {name} means one tab per value of this part. Anything after the pattern is ignored (unless the pattern contains ?, then the query is matched too).
Examples: dev.azure.com/*/*/_git/*/pullrequest/* gives one PR tab; dev.azure.com/*/*/_git/{repo}/pullrequest/* gives one PR tab per repo.

Online rulesets

A JSON file like {"name": "ADO", "rules": [{"name": "One PR tab", "pattern": "dev.azure.com/*/*/_git/*/pullrequest/*", "onMatch": "navigate"}]}. onMatch is navigate (show the new URL in the existing tab, default) or switch.
